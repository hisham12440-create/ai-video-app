# مونتاج AI

تطبيق أندرويد يصنع فيديو بستايل **المونتاج الهرمي التفاعلي (IPE)** من تسجيلك الصوتي ومصادرك وصورك.
يعمل **بدون مفاتيح وبدون إنترنت**: أنت تحدّد التوقيتات، والتطبيق يرسم ويصدّر.

## كيف يعمل
1. أنشئ **مشروعاً** (من القائمة الجانبية) واختر **التسجيل الصوتي**.
2. أضف **المصادر**: المؤلف، الكتاب، الناشر والطبعة، المجلد/الصفحة، النص المقتبس، الغلاف.
3. افتح **المحرر** وحدّد التوقيتات:
   - شغّل الصوت واضغط **علّم هنا** عند بداية الكلام عن المصدر، ولحظة التظليل، ولحظة ظهور الخلاصة.
   - اضغط على كلمة من النص المقتبس لتظليلها، وكلمة ثانية لتوسيع التظليل.
   - شاهد **معاينة الإطار** نفسها التي ستظهر في الفيديو، وحرّك الخط الزمني للتنقل.
4. اضغط السهم ↑ لإنشاء الفيديو. يُصدَّر MP4 عمودي ويُحفظ في المعرض: `Movies/MontageAI`.

> المراجع تُؤخذ **فقط** مما تدخله أنت. التطبيق لا يخترع بيانات، ويعلّم الحقول الناقصة.
> أي توقيت تتركه فارغاً يأخذ قيمة افتراضية معقولة (توزيع متساوٍ للبدايات).

## أدوات المحرر
- خط زمني بموجة الصوت وعلامات كل مصدر (بداية / تظليل / خلاصة)، والنقر أو السحب للتنقل.
- تشغيل وإيقاف وقفز ±5 ثوانٍ، وضبط دقيق ±0.1 ثانية لكل علامة.
- **توزيع متساوٍ** و**ترتيب حسب الوقت** و**مسح كل التوقيتات**.
- تحريك ترتيب المصادر، **تراجع** عن آخر 30 تعديلاً.

## خيارات الفيديو
الجودة (540p / 720p / 1080p)، لون قلم التظليل، خلفية الورق (قديم / كرافت / أبيض)، الزوم السينمائي، مستوى المؤثرات الصوتية.

## الحصول على التطبيق (APK)
كل دفعة على `main` تبني ملف APK تلقائياً عبر GitHub Actions:
- افتح تبويب **Releases** في المستودع، وحمّل `app-debug.apk` من آخر إصدار، ثم ثبّته على جوالك.

## الخطوط (اختياري)
ضع الملفات التالية في `app/src/main/assets/fonts/` لتُستخدم تلقائياً في الفيديو، وإلا تُستخدم خطوط أندرويد العربية:
`Tajawal-Bold.ttf` · `Amiri-Regular.ttf` · `Kufam-Regular.ttf`

## مرجع الستايلات
- `docs/styles/style2-ipe-handbook.md` — الدليل الكامل لستايل IPE (هذا هو المنفَّذ حالياً).
- `docs/styles/style1-ui-morphing.txt` — ستايل UI Morphing (بروبمت جاهز لخدمة توليد فيديو، المرحلة التالية).
