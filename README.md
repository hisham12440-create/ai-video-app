# مونتاج AI

تطبيق أندرويد يصنع فيديو بستايل **المونتاج الهرمي التفاعلي (IPE)** من تسجيلك الصوتي ومصادرك وصورك.

## كيف يعمل
1. ترفع **التسجيل الصوتي** وتضيف **المصادر** (المؤلف، الكتاب، الناشر والطبعة، المجلد/الصفحة، النص المقتبس، الغلاف).
2. التطبيق يحوّل الصوت إلى نص مع **توقيت كل كلمة** (OpenAI Whisper).
3. **المخرج** (Claude) يقرأ النص والمصادر ويكتب خطة المونتاج: أي بطاقة تظهر ومتى، وأي عبارة تُظلَّل، والخلاصة المكتوبة بخط اليد.
4. محرك الرسم ينفّذ الخطة حرفياً بقواعد الدليل: ورق قديم، بطاقة توثيق، قصاصة ممزقة، تظليل أصفر متزامن مع نطق الكلمة، خط حي، زوم، ومؤثرات ورق وقلم بدون موسيقى.
5. يُصدَّر MP4 عمودي (720×1280) ويُحفظ في المعرض: `Movies/MontageAI`.

> المراجع تُؤخذ **فقط** مما تدخله أنت. التطبيق لا يخترع بيانات، ويعلّم الحقول الناقصة.

## الحصول على التطبيق (APK)
كل دفعة على `main` تبني ملف APK تلقائياً عبر GitHub Actions:
- افتح تبويب **Releases** في المستودع، وحمّل `app-debug.apk` من آخر إصدار، ثم ثبّته على جوالك.

## المفاتيح
من زر **إعدادات المفاتيح** داخل التطبيق (تُحفظ على الجوال فقط):
- **مفتاح OpenAI**: مطلوب لتفريغ الصوت وتوقيت الكلمات.
- **مفتاح Claude**: اختياري. بدونه يوزّع التطبيق المصادر على طول الصوت بشكل متساوٍ بلا خلاصات.

## الخطوط (اختياري)
ضع الملفات التالية في `app/src/main/assets/fonts/` لتُستخدم تلقائياً، وإلا تُستخدم خطوط أندرويد العربية:
`Tajawal-Bold.ttf` · `Amiri-Regular.ttf` · `Kufam-Regular.ttf`

## مرجع الستايلات
- `docs/styles/style2-ipe-handbook.md` — الدليل الكامل لستايل IPE (هذا هو المنفَّذ حالياً).
- `docs/styles/style1-ui-morphing.txt` — ستايل UI Morphing (بروبمت جاهز لخدمة توليد فيديو، المرحلة التالية).
