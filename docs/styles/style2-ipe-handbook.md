# 📐 الدليل المرجعي الشامل لستايل «المونتاج الهرمي التفاعلي» (IPE)
## Interactive Pyramid Editing Style — Master Production Handbook
**النسخة المعتمدة (v5.0) — الهوية البصرية، الصوتية، والهندسية للقناة**

---

## 🏛️ 1. الفلسفة العامة وهدف الستايل (Brand Philosophy)

ستايل **«المونتاج الهرمي التفاعلي» (IPE)** هو نظام مونتاج ثوري صُمم خصيصاً للقنوات الفكرية والأكاديمية والدعوية الإسلامية (مقارنة الأديان، نقد الإلحاد، إثبات وجود الله). 

### أركان الفلسفة الثلاثة:
1. **الأكاديمية الصارمة (10/10 Fortress):** تحويل المحتوى من مجرد "كلام خطابي" إلى **حصن أكاديمي مرجعي** موثق بالمجلد والصفحة والطبعة، يصمد أمام الفلاسفة والمتخصصين.
2. **البناء التراكمي (Cumulative Case):** لا يعتمد على برهان منفرد ولا يدعي "إثباتاً مخبرياً مطلقاً"، بل يبني طبقات استدلالية متساندة؛ كل طبقة تجيب عن سؤال وتضيق فضاء التفسيرات البديلة.
3. **التفاعل البصري الحركي (Interactive Visual Network):** المشاهد لا يشاهد مقطع فيديو سكونياً، بل يرى **عقلاً يُفكر ويرسم أمام عينيه حياً** عبر خطوط تُخط وتُظلل بالتزامن اللحظي مع الصوت.

## 🎨 2. هوية الألوان والبصريات (Color Palette & Texture)

يعتمد الستايل على خامة أساسية واحدة ومجموعة محددة من الألوان الوظيفية التي تُستخدم لدلالات معنوية ثابتة لا تتغير إطلاقاً طوال الفيديو.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            خامة الورق القديم البيج                           │
│                      Parchment Texture (#F4F1EA)                            │
└─────────────────────────────────────────────────────────────────────────────┘
      │                     │                     │                     │
      ▼                     ▼                     ▼                     ▼
┌───────────┐         ┌───────────┐         ┌───────────┐         ┌───────────┐
│ الأسود الفاحم │         │ الأصفر الشفاف│         │ الأخضر الزمردي│         │ الأحمر العنابي │
│  #1A1A1A  │         │  #FFE600  │         │  #2E7D32  │         │  #8B0000  │
└───────────┘         └───────────┘         └───────────┘         └───────────┘
 (العناوين والحدود)     (التظليل الحي)        (النتائج والردود)       (الاعتراضات والشبه)
```

### جدول دلالات الألوان والاستخدام البرمجي:

| اللون | كود الهكس (HEX) | الاستخدام المحدّد | وضع المزج (Blend Mode) |
| :--- | :--- | :--- | :--- |
| **ورق قديم (Parchment)** | `#F4F1EA` | الخلفية الثابتة الملموسة للتايم لاين بالكامل | Normal (V1) |
| **أسود فاحم (Ink Black)** | `#1A1A1A` | النصوص الأساسية، الإطارات، خطوط الرسم، الأسهم | Normal |
| **أصفر شفاف (Highlighter)** | `#FFE600` | التظليل التفاعلي الحي على الكلمات المفتاحية والأرقام | **Multiply** أو **Darken** (شفافية 75%-85%) |
| **أخضر زمردي (Emerald)** | `#2E7D32` | إطارات "الرد 🟢"، علامات صح (✓)، النتائج المقبولة، PSR | Normal |
| **أحمر عنابي (Burgundy)** | `#8B0000` | إطارات "الاعتراض 🔴"، علامات خطأ (❌)، المغالطات، Brute Fact | Normal |
| **ذهبي شفاف (Gold Glow)** | `#D4AF37` | إضاءة الفروع المكتملة وعقدة "واجب الوجود" | Screen / Add (Opacity 40%) |

## 📝 3. هرمية الخطوط والطباعة (Typography Hierarchy)

تُستخدم 3 عائلات من الخطوط حصراً لخلق التوازن بين الأكاديمية واللمسة الإنسانية اليدوية:

```
                  ┌─────────────────────────────────────┐
                  │    خط العناوين الرئيسية والافتات    │
                  │           Tajawal (Bold/Medium)     │
                  └──────────────────┬──────────────────┘
                                     │
                  ┌──────────────────┴──────────────────┐
                  │    خط النصوص الأكاديمية والمراجع     │
                  │           Amiri (Regular/Bold)      │
                  └──────────────────┬──────────────────┘
                                     │
                  ┌──────────────────┴──────────────────┐
                  │    خط الخلاصة والتسطير اليدوي       │
                  │           Caveat / Kufam            │
                  └─────────────────────────────────────┘
```

1. **خط العناوين واللافتات (Banners & Level Headers):**
   - **الخط:** `Tajawal` (Bold / Medium).
   - **الخصائص:** نظيف، هندسي، واضح جداً للرؤية على الهواتف.
2. **خط النصوص الأكاديمية والاقتباسات (Citations & Main Body):**
   - **الخط:** `Amiri` (Regular / Bold) أو `Traditional Arabic`.
   - **الخصائص:** يعطي انطباع الرصانة والكتب والمراجع الأكاديمية العتيقة.
3. **خط الخلاصة والملاحظات اليدوية (Handwritten Notes):**
   - **الخط:** `Caveat` (للنصوص الإنجليزية) و `Kufam` أو `Sultani` (للنصوص العربية اليدوية).
   - **الخصائص:** يبدو كأنه كُتب بذات اللحظة بقلم حبر أو قلم رصاص، ويُوضع دائماً أسفله خط مسطر بضربة فرشاة يدوية.

## 🖼️ 4. قواعد بناء البطاقات المعيارية (Master Cards Architecture)

يتكون النظام من **4 نماذج بصريّة ثابتة** تُبنى بدقة هندسية:

---

### 🏛️ النموذج (1): بطاقة التوثيق الأكاديمي المعياري (Master Evidence Card)

تُستخدم عند استشهاد بكتاب، دراسة، أو ورقة علمية.

```
================================================================================
                               [الخلفية: ورق قديم بيج #F4F1EA]
================================================================================

[الجزء الأيسر - الغلاف والبيانات]:            [الجزء الأوسط - القصاصة الممزقة (Torn Paper)]:
┌───────────────────────────┐                 _________________________________________________
│                           │                /  Page [الصفحة]              Chapter [الفصل]     \
│     صورة غلاف الكتاب     │                |                                                 |
│     أو الورقة العلمية    │                |   [صورة لوحة كلاسيكية إنتيك بالأبيض والأسود]    |
│                           │                |                                                 |
└───────────────────────────┘                |   "النص الأكاديمي الأصلي بلغته..."             |
المؤلف / الباحث: [الاسم الكامل]               |   [تظليل أصفر شفاف #FFE600 على السطر المفتاحي]  |
الناشر والطبعة: [الدار / السنة]              \_________________________________________________/
المجلد / الفصل / الصفحة: [البيانات]
------------------------------------------------------------------------------------------------
[الجزء الأسفل - التفريغ والنص اليدوي]:

"التفريغ النصي المترجم بخط طباعي نظيف (Tajawal/Amiri)..."

خلاصة: [الجملة الختامية المكتوبة بخط يدوي Kufam/Caveat]
____________________________________________________ (سهم انسيابي + خط مسطر بفرشاة حبر سوداء)
```

---

### 📜 النموذج (2): بطاقة الاستدلال الرباعية الجامعة (Master Reasoning Card)

تُستخدم في نهاية كل مستوى هرمي (Level) لتلخيص القضية وحسمها.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          — LEVEL [X]: [عنوان المستوى] —                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1️⃣ [المقدمات والنتيجة]: (إطار أسود #1A1A1A)                                │
│ • المقدمة الأولى + المقدمة الثانية ➔ النتيجة المرحلية.                        │
│ (أيقونة خطية كلاسيكية: كتب / رسم تخطيطي)                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ 2️⃣ [الاعتراض 🔴]: (إطار أحمر عنابي #8B0000)                                │
│ • أقوى اعتراض فلسفي أو علمي يطرحه الخصم بدقة وبلسان أصحابه.                 │
│ (أيقونة خطية: مثلث تحذير ⚠️)                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ 3️⃣ [الرد 🟢]: (إطار أخضر زمردي #2E7D32)                                    │
│ • الجواب المنضبط الأكاديمي الذي يفكك الاعتراض دون ادعاء مبالغ فيه.          │
│ (أيقونة خطية: مصباح متوهج 💡)                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ 4️⃣ [الخلاصة المسطرة]: (إطار أسود #1A1A1A)                                    │
│ • الجملة المنضبطة المكتوبة بخط يدوي مع تسطير أسود حبر تحتها.                 │
│ (أيقونة خطية: عدسة مكبرة 🔍)                                                │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

### 🕸️ النموذج (3): شجرة قمة الهرم والشبكة التفاعلية (Pyramid Node Tree)

تُستخدم لبناء العلاقات بين البراهين وإظهار تفرع الخيارات الميتافيزيقية.

```
                          ┌──────────────────────────┐
                          │   سؤال التفسير الوجودي   │
                          └────────────┬─────────────┘
                                       │
                       ┌───────────────┴───────────────┐
                       │  (خطوط سوداء حية ترسم حياً)   │
                       ▼                               ▼
        🔴 [الفرع الأيسر - عنابي #8B0000]       🟢 [الفرع الأيمن - زمردي #2E7D32]
      ┌─────────────────────────────────┐     ┌─────────────────────────────────┐
      │          Brute Fact             │     │              PSR                │
      │        (واقعة مجردة)            │     │      (مبدأ السبب الكافي)        │
      └─────────────────────────────────┘     └─────────────────────────────────┘
```

---

### ⚔️ النموذج (4): لوحة المقارنة المنهجية الثنائية (Contrast / VS Scene)

تُستخدم في المقدمات للمقارنة بين المناهج الخاطئة والمناهج الصحيحة.

```
┌─────────────────────────────────┐   VS   ┌─────────────────────────────────┐
│  [إطار أحمر عنابي #8B0000]       │        │  [إطار أسود فاحم #1A1A1A]       │
│  اختبار مخبري منفرد             │        │  قضية تراكمية متكاملة           │
│  (غير متاح في الميتافيزيقا)      │        │  (Cumulative Case)              │
│  علامة حمراء: ❌                 │        │  علامة خضراء متألقة: ✓          │
└─────────────────────────────────┘        └─────────────────────────────────┘
```

## 🔊 5. هوية الهندسة الصوتية (Sound Design — No Music Rules)

**القاعدة المطلقة:** يمنع استخدام أي خلفيات موسيقية أو إيقاعات إلكترونية نهائياً. يتم الاعتماد الكلي على **المؤثرات الصوتية الواقعية (Foley & SFX)** لإعطاء وزن وهيبة وحيوية لكل حركة بصريّة.

```
   [صوت المتحدث Voiceover (A1)] ➔ معالج ومصفى عند -14 LUFS
                │
                ├── 📄 Foley الصوتيات الورقية (A2): Paper Flip, Paper Slide
                ├── ✏️ Foley الكتابة والرسم (A2): Pencil Scratch, Marker Squeak
                ├── 🪵 Foley الحركة والتفرع (A3): Wood Click, Mechanical Snap
                └── 🔊 المؤثرات السينمائية (A4): Sub-Drop, Warning Beep, Light Glow
```

### مصفوفة المؤثرات الصوتية المعتمدة والتوقيت:

| الحدث البصري على الشاشة | المؤثر الصوتي المعتمد (SFX Asset) | طبيعة الصوت |
| :--- | :--- | :--- |
| **ظهور بطاقة كتاب أو ورقة** | `Paper_Flip.wav` / `Paper_Slide.wav` | تقليب أو انزلاق صفحة ورقية سميكة |
| **رسم التظليل الأصفر (Highlighter)** | `Marker_Squeak.wav` | صوت احتكاك قلم الفلوماستر بالورق |
| **رسم الخطوط والأسهم والتسطير** | `Pencil_Scratch.wav` / `Ink_Draw.wav` | صوت حك سن القلم بالورقة الخام |
| **تفتح فرع هرمي جديد أو كارت** | `Wood_Click.wav` / `Mechanical_Snap.wav` | طقة خشبية هادئة أو نقرة ميكانيكية |
| **ظهور الشبهة أو الاعتراض 🔴** | `Warning_Soft_Beep.wav` | نبضة تحذير تنبيهية خفيفة غير مزعجة |
| **ظهور الرد والإضاءة الفكرية 🟢** | `Light_Bulb_Sparkle.wav` | صوت توهج ناعم يرمز لانبثاق الفكرة |
| **ظهور الخلاصة وحسم المستوى** | `Cinematic_Sub_Drop.wav` | نبضة عميقة جداً (Deep Low-Frequency) |

## 🎥 6. قواعد حركة الكاميرا والتحريك (Motion Dynamics & Camera Rules)

لضمان ألا يبدو الفيديو كعرض شرائح جامد، تُطبق 4 قواعد حركية صارمة:

### 1. قاعدة التزامن اللحظي (Lip-Sync Line Draw):
لا يظهر أي خط، سهم، أو تظليل أصفر على الشاشة إلا **في نفس الثانية واللحظة التي ينطق فيها المتحدث الكلمة المفتاحية**. ظهور العناصر قبل أو بعد الصوت يكسر الاندماج المعرفي.

### 2. قاعدة العزل التفاعلي (Focus Shift & Blur):
عند الانتقال للشرح داخل عنصر محدد (مثلاً: مناقشة اعتراض Brute Fact):
- يُطبَّق زوم (`Zoom In 130%`) نحو العنصر النشط.
- تُطبَّق ضبابية (`Gaussian Blur = 15%`) وتخفيض إضاءة (`Brightness = -20%`) على جميع العناصر الأخرى غير النشطة على الشاشة.

```
   [عنصر غير نشط] ➔ (Blur 15% + Dark -20%)
   [العنصر النشط]  ➔ (Zoom 130% + Brightness 100% + Yellow Highlight)
   [عنصر غير نشط] ➔ (Blur 15% + Dark -20%)
```

### 3. قاعدة التظليل التفاعلي الشفاف (Multiply Highlighting):
يُرسم مستطيل التظليل الأصفر `#FFE600` من اليسار إلى اليمين باستخدام `Mask / Split Keyframes` خلال زمن قدره `0.4 sec` إلى `0.6 sec` مع تفعيل `Blend Mode: Multiply` ليبقى النص المطبوع واضحاً تحته.

### 4. قاعدة الكاميرا السينمائية التراكمية (Tilt & Pan):
عند عرض بطاقات الاستدلال الرباعية:
- تبدأ الكاميرا بزوم قريب على البلوك 1.
- تتحرك رأسياً لأسفل (`Pan Down`) مع كل بلوك جديد.
- ترجع الكاميرا بزوم واسع (`Zoom Out 100%`) عند نهاية المقطع لكشف البطاقة أو الهرم كاملاً.

## 🛠️ 7. دليل إعداد بيئة العمل على البرامج (Software Setup Workflow)

### 🟢 أولاً: تطبيق الستايل على CapCut PC

1. **هندسة التايم لاين (Timeline Tracks):**
   - **V6:** `Adjustment Layer` (تأثيرات Blur والعزل).
   - **V5:** مستطيلات التظليل الأصفر `#FFE600` (`Blend Mode = Multiply`).
   - **V4:** النصوص البطاقية والمراجع والقصاصات الممزقة (Torn Paper PNG).
   - **V3:** الخطوط والأسهم السوداء الحية `#1A1A1A`.
   - **V2:** المتحدث / الأيقونات الخطية.
   - **V1:** خلفية الورق القديم الثابتة `#F4F1EA`.
2. **إنشاء العقدة التفاعلية (Compound Clip):**
   - عند إتمام عناصر البطاقة، حدد طبقات V3 + V4 + V5 واضغط `Right Click > Create Compound Clip` (أو `Alt+G`).
   - تحريك البطاقة الآن بالزوم أو الانزلاق يتم على الكومبوند كقطعة واحدة دون تفكك العناصر.
3. **رسم الخطوط بالأقنعة (Masking):**
   - اختر الخط الأسود، اذهب إلى `Video > Mask > Split`.
   - ضع Keyframe عند بداية الكلمة (الخط مخفي)، وKeyframe بعد `0.4 sec` (الخط مكتمل الظهور).

---

### 🔵 ثانياً: تطبيق الستايل على DaVinci Resolve

1. **بناء البطاقات في Fusion Page:**
   - اسحب خلفية `Parchment` واربطها بـ `Merge Node`.
   - اسحب النص والأغلفة واربطها بـ `Merge Nodes` متتالية.
   - أضف `Background Node` بلون أصفر `#FFE600` واضبط `Apply Mode` في الـ Merge الخاص به على `Multiply`.
2. **رسم الخطوط والأسهم الحية (Paint Node):**
   - أضف `Paint Node` بين المسارات.
   - اختر أداة `Polyline Stroke` وارسم المسار الهرمي أو السهم المتعرج.
   - اذهب إلى إعدادات `Stroke Controls` وضع Keyframes على خاصية `Write On` ينقل القيمة من `0.0` إلى `1.0`.
3. **الماسترينغ الصوتي (Fairlight Page):**
   - اضبط مستوى صوت المتحدث في القناة `A1` ليكون عند **`-14 LUFS`** ثابتة.
   - ضع مؤشرات المؤثرات الصوتية Foley في `A2` و `A3` لتبلغ ذروتها عند **`-18 dB`** لكي لا تغطي على صوت المتحدث.

## 🏆 الخلاصة التنفيذية

ستايل **IPE (المونتاج الهرمي التفاعلي)** ليس مجرد شكل جمالي، بل هو **لغة معرفية هندسية**. عندما يرى المشاهد خلفية الورق القديم، والخطوط التي ترسم حياً، وبطاقات المراجع الموثقة بدقة، والتظليل الأصفر المتزامن مع الصوت، فإنه يستقر في شعوره الباطن أنه أمام **محتوى أكاديمي رفيع المستوى** لا يمكن الاستخفاف به أو ضربه بتعليق سطحي.

هذا الدليل هو المرجع الثابت لجميع فيديوهات وشورتس وريلز القناة.
